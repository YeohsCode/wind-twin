# 3D Model Attribution

## `tower.glb` and `turbine_lq.glb`

- **Model:** IEA Wind Task 37 / NREL / DTU / TUDelft IEA-15-240-RWT low-polygon derivatives
- **Source:** [IEA-15-240-RWT](https://github.com/IEAWindSystems/IEA-15-240-RWT)
- **License:** [Apache License 2.0](https://github.com/IEAWindSystems/IEA-15-240-RWT/blob/master/LICENSE)
- **Usage:** `tower.glb` is extracted once and rendered as one `InstancedMesh` covering every active farm position (~164 in the target layout); `turbine_lq.glb` is loaded once and cloned only for the selected-turbine closeup. The closeup asset is a merged single mesh, so its rotor is intentionally static.
- **Normalization:** Scene code scales the tower uniformly to a 160 m sand-table tower and the closeup to true IEA-15MW scene proportions.

## `truck-flat.glb`

- **Model:** Flatbed truck from Kenney Car Kit
- **Source:** [Kenney Car Kit](https://kenney.nl/assets/car-kit)
- **License:** [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- **License copy:** [`LICENSES/kenney-car-kit-license.txt`](./LICENSES/kenney-car-kit-license.txt)
- **Normalization:** The source model is scaled uniformly in `SandboxScene` so its longest side represents 16 meters in the sand table.

## Crane

Direct downloads for suitable crawler-crane and full wind-turbine GLB assets were not available from the requested CC0 sources; Sketchfab CC-BY candidates required authenticated API access. The scene therefore uses its documented high-detail geometry fallback:

- Crawler crane: track assemblies, car body, counterweight, cab, lattice-style 63 m boom, and hoisted turbine component. Its geometric body/boom proportions are calibrated for a 160 m turbine.
- Wind-turbine batch positions retain a lightweight generated nacelle, hub, and three swept/curved blades when the IEA tower model is unavailable; `tower.glb` replaces only the tower geometry after loading.

These fallbacks are generated by `frontend/src/sandbox/SandboxScene.tsx` and carry no third-party attribution requirement. The loader automatically retains these fallbacks if a model request times out or fails.
